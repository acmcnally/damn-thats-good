DAMN-2 — Manual recipe entry: UX mockups

Reference apps researched: Plan to Eat, Paprika, Mela, Mealie, Tandoor — all converge on plain-text/paste-first ingredient entry with automatic quantity/unit detection, which is what all three options below build from. Owner's explicit constraint: no discrete dropdowns, no individual text boxes per ingredient, no "+ add row" buttons — entry should feel fluid, freeform text that gets intelligently tokenized for storage.
